# False Confidence

**Automated Labels Confound Fairness Audits in Cervical Spine Segmentation**

Linus Juni, Aasa Feragen, Aditya Parikh · DTU Compute, Technical University of Denmark

FAIMI-BRIDGE-EPIMI Workshop @ MICCAI 2026 (oral)

---

Modern segmentation datasets mix a few expert (**gold**) labels with many machine-generated
(**silver**) labels. We audit nnU-Net on cervical-spine MRI ([CSpineSeg](https://data.midrc.org/discovery/H6K0-A61V/))
across sex, race and age, and show that the choice of reference label is not neutral:

- **E1 — Global audit.** Scored against the dataset's labels, the deployed model shows no
  significant demographic disparities (0 of 63 tests after FDR correction; every DIR > 0.96).
- **E2 — Biased ruler.** The *same* predictions on the *same* 76 images, scored against silver
  labels generated by a gold-trained model, gain ~8 Dice points (0.897 → 0.973), and age turns
  significant (0/63 → 11/63 tests). The gap does not grow; within-group variance collapses ~4×.
  We call this **false confidence**.

The silver labels leak information from the gold labels they were derived from, so any model
trained on those gold labels agrees with them more than with expert truth.

## Installation

The project is managed with [uv](https://docs.astral.sh/uv/) and pins the exact package versions
used for the paper (Python 3.13, nnU-Net v2.7.0).

```bash
git clone https://github.com/linusjuni/false-confidence.git
cd false-confidence
uv sync
cp .env.example .env   # then edit the paths
```

## Data

CSpineSeg (1,255 sagittal T2-weighted cervical-spine MRI exams from Duke University, with
vertebral-body and disc masks) is available from MIDRC:
**<https://data.midrc.org/discovery/H6K0-A61V/>**. Download it under the MIDRC data use agreement
and arrange it as

```
$DATA_DIR/
├── annotation/     # MRI volumes           <patient>_Study-MR-<n>_Series-<n>.nii.gz
├── segmentation/   # reference masks       <patient>_Study-MR-<n>_Series-<n>_SEG.nii.gz
└── structured/     # MIDRC metadata TSVs   case_*.tsv, imaging_study_*.tsv, mr_series_*.tsv, annotation_file_*.tsv
```

**Gold vs. silver provenance.** MIDRC marks each mask's `annotation_method` as
`Retrospective_expert` (491 masks, gold) or `Retrospective_auto` (silver).
[`provenance.py`](src/false_confidence/splits/provenance.py) queries this from the public MIDRC
API. The shipped split files already include it.

**Splits.** [`splits/`](splits) holds the exact patient-level splits used in the paper
(IDs and provenance only; demographics are re-derived from the MIDRC metadata):

| File | Model | Train | Val | Test | Total |
|---|---|---|---|---|---|
| `split_mix.tsv` | M_mix (gold + silver) | 798 | 116 | 228 | 1,142 |
| `split_gold.tsv` | M_gold (gold only) | 288 | 44 | 76 | 408 |

Both are stratified by race × age × sex at the patient level (70/10/20) and sex-balanced
within each split. nnU-Net cross-validates over train + val, and the test set is held out.
[`create.py`](src/false_confidence/splits/create.py) documents how the splits were built. Use
the shipped files to reproduce the paper.

## Reproducing the paper

Training follows standard nnU-Net v2 with the ResEnc-L preset. The only change is
demographically stratified cross-validation folds. See the paper for compute details.

```bash
# 1. nnU-Net datasets, planning/preprocessing, stratified CV folds (1 = M_mix, 2 = M_gold)
bash scripts/01_prepare_nnunet.sh 1
bash scripts/01_prepare_nnunet.sh 2

# 2. Train 2 configurations x 5 folds per model
for d in 1 2; do for c in 2d 3d_fullres; do for f in 0 1 2 3 4; do
    bash scripts/02_train.sh $d $c $f
done; done; done

# 3. Ensemble and post-process the test-set predictions
bash scripts/03_predict.sh 1
bash scripts/03_predict.sh 2

# 4. Experiments E1 and E2, and Figure 1
bash scripts/04_audit.sh
```

**Without GPUs or images.** The per-case scores behind E1 and E2 are in [`results/`](results).
With only the metadata TSVs in `$DATA_DIR/structured/`, this re-runs the full statistical
analysis and Figure 1:

```bash
EVAL_DIR=results bash scripts/04_audit.sh
```

Reports (per-group summaries, FDR tables, bootstrap intervals, threshold sweeps, figures) are
written to `outputs/fairness/<experiment>/<timestamp>/`.

Descriptive analyses:

```bash
uv run python scripts/cohort_composition.py          # Table 1
uv run python -m false_confidence.confounders        # anatomical confounders (needs masks)
uv run python scripts/gold_silver_comparability.py   # gold vs. silver pool composition
```

## Paper-to-code map

| Paper | Code |
|---|---|
| Table 1: cohort composition | `scripts/cohort_composition.py` |
| Anatomical confounders | `src/false_confidence/confounders.py` |
| Splits, sex balancing, label regimes | `src/false_confidence/splits/`, `splits/*.tsv` |
| nnU-Net training (ResEnc-L, stratified folds) | `src/false_confidence/nnunet/`, `scripts/01–03` |
